# 🚀 NexHire — Job Finding & Recruitment Platform

**Live Project:** https://finding-job-web-a33o.vercel.app/

NexHire is a full-stack **MERN job recruitment platform** that connects job seekers with recruiters and companies.

## ✨ Features

### 👨‍💻 Job Seekers

* Register and login
* Browse, search, and filter jobs
* View job details
* Apply for jobs
* Create and update profile
* Upload profile picture and resume
* Track application status

### 🧑‍💼 Recruiters

* Recruiter dashboard
* Create and manage companies
* Create and manage job postings
* View applicants
* View and download resumes
* Accept or reject applications

## 🔐 Authentication

* JWT authentication
* HTTP-only cookies
* Password hashing with bcrypt
* Role-based access for students and recruiters
* Protected routes

## 🛠️ Tech Stack

**Frontend**

* React.js
* Vite
* Tailwind CSS
* Shadcn/UI
* Redux Toolkit
* React Router
* Axios

**Backend**

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* bcrypt
* Cloudinary
* Multer

## 🗄️ Database

MongoDB with Mongoose.

Main collections:

* Users
* Companies
* Jobs
* Applications

## 📱 Responsive Design

The application is responsive and works across desktop, laptop, tablet, and mobile devices.

## 📁 Project Structure

```text
NexHire

```

## ⚙️ Run Locally

```bash
git clone YOUR_REPOSITORY_URL

cd FrontEnd
npm install
npm run dev
```

For the backend:

```bash
cd BackEnd
npm install
npm run dev
```

Create a `.env` file in the backend for MongoDB, JWT, and Cloudinary credentials.
